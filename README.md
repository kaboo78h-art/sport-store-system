# Sports Store E-Commerce System

A complete e-commerce platform developed for managing and selling sports products online.

## Features

* Product management
* Customer accounts
* Shopping cart
* Order management
* Admin dashboard
* Database integration
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL

## Project Overview

This project was developed as a real-world e-commerce solution for selling sports products. The system provides a user-friendly shopping experience and an administration panel for managing products, customers, and orders efficiently.

## Key Functions

* Browse and search products
* Add products to cart
* Manage customer information
* Process orders
* Manage inventory through the admin dashboard

## Status

Project completed and actively used.
